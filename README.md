# 🍔 Sistema de Pedidos - Hamburgueria

Aplicação fullstack para gerenciamento de pedidos de uma hamburgueria, permitindo criar, listar, atualizar status e deletar pedidos em tempo real.

---

## 🚀 Acesse o projeto

- 🔗 Frontend: https://hamburgueriaapi5.vercel.app/
- 🔗 Backend (API): https://hamburgueria-api-1.onrender.com

---

## ⚙️ Funcionalidades

* ✅ Criar pedidos de hambúrguer  
* 📋 Listar pedidos em tempo real  
* 🔄 Atualizar status do pedido (PENDENTE, EM PREPARO, PRONTO, ENTREGUE)  
* ❌ Deletar pedidos  
* 🌐 Integração completa entre frontend e API  

---
